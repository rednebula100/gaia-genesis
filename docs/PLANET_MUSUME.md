# Planet Musume — rules, boundaries and acceptance

The new default is a free fictional sports game. The old GAIA engines, shaders, maps, particle counts, pipeline, scientific model and Atlas programs remain intact. Only the main entry selector, scoped canvas lookup, visible-engine suspension and non-negative RAF delta guard connect the two experiences. The fixed existing Pages base remains `/gaia-genesis/`.

## Play loop

- First visit: 6,000 free credits, Earth and seeded world 162711, three research cards. Two independent scout pools cost 100 / 1,000 for one / ten pulls. Basic grade odds are SSR 3%, SR 18%, R 79%, uniform within grade. On the first planetary ten-pull, if the first nine contain neither a new athlete nor an SSR, the tenth is SSR instead of using the basic roll. Duplicate counts improve starts/card bonuses and grant 5/12/30 research shards; 30 shards exchange for 300 credits. No payments or cash value.
- Choose one of eight actual spherical athletes and up to four of eight research cards. Ten turns track speed, endurance, gravity, spin and orbital sense; energy, mood, skill points and three two-choice events. Cards change matching training gains and failure rates. Low energy can fail; rest recovers 43 energy. Three learned skills affect drafting, corners and the final straight. The original 3D lab can consume one turn after a real task: select the inner core and change cut angle; observe seismic propagation and choose S; change live gravity; or seek prepared collision physics. Rewards are explicitly fictional and separate from the Earth-reference model. Each special task pays once per career.
- Two courses (1,800 / 2,400 m), three strategies, eight actual racers. A fixed 1/60-second model uses speed/acceleration, stamina, affinity, cornering, blocking, seeded reaction/lane decisions and seven native trigger families. Jupiter actually affects nearby opponents. Native boosts/effects are stylized game rules, not celestial physics. Finish times interpolate within the crossing step; ordering is not preselected. Opponents use seeded stats and can beat the player.
- AUTO plus four camera modes, pause, 2×, deterministic replay and Skip. Skip runs the same model to completion. Result credit payment is idempotent by race ID. The game preserves a career, inventory, selected deck, last race configuration, 30 results and 12 completed careers locally. Refreshing an ongoing race restarts that same race; exact in-progress video time is not persisted. Settings exports JSON or resets with a second confirmation. Corrupt/unsupported saves fall back with a message. Private browsing/storage denial cannot provide persistence; exporting remains available.

## Rendering and source reuse

Actual lit 128×80 sphere meshes, separately rotating clouds, bumped surfaces and atmospheric shells use existing full-resolution 2K credited NASA / Solar System Scope textures; two custom athletes use the existing 2048×1024 seeded worker maps/clouds. Source maps are not downscaled. ACES output is confined to this new renderer; original Genesis HDR/AgX and Atlas Reinhard/gamma remain unchanged. Original Stardust shaders execute in the new 120,000-particle scout assembly adapter. The separate original Origins experiment remains 420,000 particles. All seven Atlas programs remain original full-quality fullscreen shaders, not race materials. No performance-driven DPR, geometry, particle, texture or shader quality governor exists.

Only the visible game/legacy renderer animates. Shared sphere geometry/materials/textures and race effect meshes are prepared once and reused on each screen/replay. Both procedural worker jobs complete before it terminates. The legacy engine is imported once; its existing caches and cleanup remain in control. New special-training access waits for actual preparation, can return early, and ignores a cancelled handoff. First legacy warm-up may take a minute or longer on integrated GPUs; no invented progress total.

## Checks

`npm run build`; `node scripts/verify-game-model.mjs`; `node scripts/verify-game.mjs` with a production preview at port 5179 (override `GAIA_URL`). Windows Chrome and hardware ANGLE are required for the published evidence. Video requires `npx playwright install ffmpeg`. The model check tests same-config racer/event equality, two courses, actual stat/strategy effects, one-time rewards, storage restore/corruption. The browser check is one real end-to-end playthrough, not fabricated screenshots or preloaded game results. Its exact run output is [verification.json](screenshots/planet-musume/verification.json).

See [captures and revisions](screenshots/planet-musume/README.md), [reference audit](design/PLANET_MUSUME_REFERENCE_AUDIT.md) and the existing [legacy verification](VERIFICATION.md). No claim of NASA-level photographic accuracy, measured real-world physical racing, complete climate/tectonic simulation, long campaign, multiplayer, hidden Pluto, or Saturn/Neptune/Uranus rendering. No audio was added. These are intentionally outside this playable slice.
